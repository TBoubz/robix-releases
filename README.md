# Robix — test builds

Chrome extension **UGC Sales Dashboard for Roblox** (compiled build only), version 2.1.0.

**Download:** [robix-extension.zip](https://github.com/TBoubz/robix-releases/raw/main/robix-extension.zip)

Install: unzip, open `chrome://extensions`, enable *Developer mode*, *Load unpacked*, pick the unzipped folder.
